The World Wide Web (WWW or Web) is a decentralized information system of interlinked, multimedia documents (webpages) and resources accessed via the internet using browsers. Invented by Tim Berners-Lee in 1989, it operates on a client-server model, using URLs for identification and HTTP for transferring data.
